# Advanced Modular IoT Air Quality Index (AQI) Monitoring System with GSM SMS Alerts 🚀🌫️  
Reliable air monitoring with real-world GSM alerting.

This project implements a **modular IoT Air Quality Index (AQI) monitoring system** using an **ESP32**, **MQ-135 air quality sensor**, and a **SIM800L GSM module**.

Unlike Wi-Fi-based systems, this solution works independently using GSM communication, making it ideal for remote or low-connectivity environments.

The system is structured using a **multi-file professional architecture**, separating configuration, sensor logic, and GSM communication.

---

## 🧠 Project Overview

Air pollution can cause severe health issues.  
This system continuously monitors air quality and automatically sends SMS alerts when pollution exceeds safe levels.

### System Architecture


The system includes cooldown protection to prevent repeated SMS spam.

---

## ⚡ Key Features

- Real-time AQI monitoring
- High-resolution ESP32 ADC (0–4095)
- Automatic SMS alerts on poor air quality
- Cooldown timer to prevent repeated alerts
- Modular multi-file code structure
- Separated configuration file
- Serial debug monitoring
- Works without Wi-Fi
- Designed using scalable embedded architecture
