
# Advanced Modular IoT AQI Monitoring System with GSM Alert 🚀

ESP32-based Air Quality Monitoring system using MQ-135 and SIM800L.

## Features
- Modular multi-file structure
- Clean separation of sensor, GSM, and config logic
- SMS alert with cooldown protection
- Professional project structure

## Folder Structure
- src/ → Main program
- include/ → Header files
- docs/ → Hardware notes
